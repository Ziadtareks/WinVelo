# WinVelo Evidence Audit Report

This document records the formal re-audit of the `evidence` field across all 149 tweaks in the WinVelo catalog, enforcing the strict evidence rule:
> **Strict Evidence Rule**: A tweak may ONLY be classified as `documented` if an official vendor documentation page (Microsoft Learn / Microsoft Docs) explicitly names the setting (the exact registry value name, policy name, or CSP property). A generic documentation page about the subsystem does not qualify. If the setting is not explicitly named, the tweak is classified as `situational` (or `anecdotal` for speculative performance claims). Every `documented` tweak must store the exact excerpt in its `sourceQuote` property.

---

## Evidence Summary

| Evidence Level | Count | Definition |
|---|---|---|
| **Documented** | **16** | Verified official documentation explicitly naming the setting with an exact quoted excerpt in `sourceQuote`. |
| **Situational** | **131** | Legitimate Windows settings or community tools whose cited documentation discusses the subsystem generally but does not explicitly document the specific registry key/value. |
| **Anecdotal** | **2** | Speculative or unverified community tweaks with no measurable, documented empirical performance benefit. Quarantined behind `needsReview: true`. |
