# WinVelo Roadmap

- **Phase 0**: Architecture, JSON Schema, and Project Tree. (Completed)
- **Phase 1**: Solution Setup, .NET 10, WPF Fluent Shell, en/ar RTL, Logging, CatalogValidator. (In Progress)
- **Phase 2**: Core Engine: Registry/Service/Task action execution, Rollback Journal, Dry-Run, and Unit Tests with Fakes.
- **Phase 3**: Tweaks Catalog UI, initial 40 verified tweaks, and Presets (Recommended, Privacy, Gaming, Minimal).
- **Phase 4**: Dashboard, Startup Manager, Services Manager, Smart Cleaner.
- **Phase 5**: App Installer (WinGet), Uninstaller, Fixes Center, Network Tools.
- **Phase 6**: Expanded Catalog (150+ verified tweaks).
- **Phase 7**: Toolbox completion, Profiles, Command Palette, CLI mode.
- **Phase 8**: Final polish, Inno Setup installer, Accessibility, and v0.1.0 release.
